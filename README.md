# Music Forge Next

A local music generator that turns a style, mood and seed into an editable instrumental track.

## Key features

- Generate music without an account, cloud service or AI model.
- Change instruments and mix individual tracks while listening.
- Export WAV, Opus and MIDI, or save project settings.

## Get started

Download the Windows ZIP, install Python 3.12, run `Nainstalovat.cmd`, then `Spustit Music Forge.cmd`. The interface is currently in Czech.
